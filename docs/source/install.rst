## How to install `pydiosrt` 📌

Install System Libraries
------------------------

- MacOS:

.. code-block:: bash

    brew bundle

- Ubuntu Linux:

.. code-block:: bash

    sudo apt install clang-format

- Redhat Linux:

.. code-block:: bash

    sudo yum install clang-tools-extra

Install python libraries
~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    pip install -r requirements.txt

Install pre-commit
~~~~~~~~~~~~~~~~~~

.. code-block:: bash

    pre-commit install
