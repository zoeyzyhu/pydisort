# Contributing

Please use the [contributor guide](https://pydisort.readthedocs.io/en/latest/contribute.html)
for environment setup, branch/PR workflow, validation commands and conventions.
Its [source](docs/source/contribute.rst) lives alongside the rest of the documentation.

For a substantial change, start with a [GitHub issue](https://github.com/zoeyzyhu/pydisort/issues).
Small documentation fixes can go directly to a PR against `main`.

Before submitting, review all changes, run the relevant tests and formatting
checks, and include the exact commands and results in the PR description.
Pre-commit hooks do not replace the solver tests.
